Actual-model suites
  scripts/extended_model_fixtures.py generates deterministic paired tasks.
  scripts/extended_model_launch.py hermes / openclaw runs native frameworks.
  scripts/extended_model_summarize.py independently validates result.json.
  scripts/extended_vision_fixtures.py generates the10identical-image fixtures.
  scripts/extended_vision_launch.py hermes / openclaw runs native image routes.
  Model deepseek-flash, thinking disabled, temperature0,1536output tokens for
  data/skill/document tasks and256for image extraction. Each framework sees
  the same case inputs, although native prompt/tool preparation differs.
  Repeat only when desired: these commands use the configured account credits.
  No key is stored in this artifact tree or its archive.

Environment
  Pinned commits and toolchain remain in results/environment-final.json.
  Source-mode API execution is used. First source import/compilation overhead
  and whole cold process RSS are not production package performance results.
  Local SSH endpoints share a host; no WAN/cloud-scale conclusion.
  Browser tasks use fixed actions; no claim of autonomous visual planning.
  Provider25uses a deterministic protocol fixture, not a neural inference engine.
  CPU20uses a fixed local model response, so native CPU excludes external
  model inference work; imported source/native-worker overhead is scoped.

Aggregation and rendering
  In the prepared task directory:
    python3 scripts/extended_model_summarize.py
    envs/report/bin/python scripts/render_full_report.py
    python3 scripts/package_results.py --archive-name full-results.zip
  Full renderer refuses missing/nonfinite observations or incorrect pass-rate
  denominators. Native real-model failures would remain failures, while verified
  harness setup attempts are preserved separately in raw/setup-invalid-models/.

Security and cleanup
  runtime/,envs/,sources/and container layers are never bundled.
  SSH private keys are only in taskruntime and excluded from packages.
  DeepSeek private key is outside taskoutputs and never included.
  The final archive is scanned against the configured credential without
  printing credential values or fingerprints.
