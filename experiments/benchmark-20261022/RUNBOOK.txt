Interpretation boundaries
  06: native backend prepare+first command; images preloaded; both1CPU/512MiB/
      128PIDs/networknone. Backend-specific preparation remains included.
      Source-mode timing is not a released Gateway benchmark.
  08: actual tools in one conversation/stdioMCP connection per framework,
      35batches×4calls; first5warmup, next30measure. Every tool waits200ms.
      Tool events and native results validate140actualcalls and36modelrequests
      per framework. Interquartile error bars describe within-session batches.
  23: native catalog APIs,10/100/500identical skills; each SKILL.md5011bytes.
      Cold means application cache cold, OS cache warm, imports excluded.
      OpenClaw capacity raised explicitly so500skills really load. Asymmetric
      direct-read API timings remain raw secondary data and are not ranked.
  26: three actual kernel pressure checks repeated3times each per framework.
      Formal memory checks disable swap. The original swap-enabled preflight
      is preserved at raw/quota-preflight-swap-allowed.json; allocation above
      resident-memory limit was valid under that earlier combined limit.
  20: source initialization RSS and startup times are deliberately not ranked.

The archive intentionally omits sources/, envs/, runtime/, container layers and
all private credential files. For a fresh machine fetch the commits above,
install their frozen dependencies and rebuild the required canonical helper.

Public model/fixture configuration snapshots are in configs/. For a fresh
workspace copy those JSON files to envs/ after restoring the toolchain.
They contain only an environment-variable reference or a local synthetic key.
