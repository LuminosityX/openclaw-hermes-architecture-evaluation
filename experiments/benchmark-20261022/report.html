05. 上下文管理

测量范围：12组固定长工具输出：32k/128k上下文×20k/100k/500k字符×ASCII/中英emoji。执行原生裁剪/存储函数，检查内联结果不超各自原生预算、缩减时存在提示、原始输出在原消息或原生spill档案中保持SHA-256完整。

  • 这是长工具输出保护组件实验，未测真实模型回答、压缩摘要质量、长期事实问答或实际API Token。
  • OpenClaw在此路径保留原toolResult消息并投影裁剪；没有自动返回spill档案路径。Hermes超阈值写spill档案并返回读取路径。原消息保留不等于模型能自动读取全文，未将这两种机制当作同等检索能力。
  • 两边默认预算不同，OpenClaw按加权字符计量预算、Hermes按Python字符数计量预算，内联比例只描述默认策略，不以越小越好排名。
  • 档案SHA只核验原生返回的文件路径，未给OpenClaw补造spill文件；非ASCII输入使用相同UTF-8文件。

      20. 资源轻量化

      测量范围：Complete native minimal text-turn CPU time, three same-process warmups followed by ten measured fresh sessions per framework; same deterministic local OpenAI-compatible endpoint, 128k context, output cap128, reasoning disabled, temperature omitted and no advertised tools. OpenClaw production agentExecCommand versus Hermes AIAgent construction, run_conversation and close. CPU = /proc/self/stat user + system + waited child CPU; 100Hz OS clock gives 10ms resolution.

      • This is the fixed source-API harness (Node 24 with tsx/jiti versus Hermes Python), not packaged-release or whole-Gateway performance. Imports and first-turn compilation are excluded, but native on-demand source/runtime work inside later turns remains included.
      • Measures CPU for a trivial successful framework turn with no tools; excludes actual LLM inference, real API latency/charges, production messaging gateways and enabled plugin stacks.
      • Active detached descendants not yet reaped are not included by cutime/cstime; tool-free runs do not spawn task workloads. Node worker-thread CPU is part of process CPU.
      • Runtime semantics and lifecycle implementation differ; this is the measured harness resource cost, not a general speed ranking. Idle-controller constructor and unstable resident-memory diagnostics are separate secondary artifacts.
