# OBS-04: native record retention, archival and modification

All four frozen scenarios run against the pinned unmodified core, after whole-family native calibration, with three fresh independent units each. Deterministic transcripts and independent owned receipts are used; no paid model is called. All native state and the at most 128 MiB tmpfs remain on disposable hosted runners.

- S01 offers 320 unique logged events from a real plugin tool, against a configured 16 KiB native file rotation limit and the shipped five older generations. The newest event must survive, older events must actually cross the rotation boundary, and native files must obey count and size bounds. The burst is below the shipped 4096-record queue capacity. An explicit owner `sessions.delete` also exercises transcript pruning. This measures native bounded diagnostic retention, without assuming logs are a durable audit spool.
- S02 creates, independently verifies and restores an actual native full backup into fresh staging. Every column of every bounded `transcript_events` row, including IDs and binary payloads, contributes to an independently compared digest. More than 1000 rows fails the oracle instead of silently claiming complete fidelity. This is the product's backup/restore record roundtrip; public history JSON is not asserted to be an import format, and activation at another path is not inferred.
- S03 places a full synthetic secret in an actual native file read and plugin log, verifies it reaches the fixture model, and checks configured full-pattern redaction in the native file, `chat.history` and `logs.tail`. Other formats and partial masked fragments are outside this exact-pattern assertion.
- S04 performs a real UID/GID 65534 file mutation attempt under an explicitly recorded 0700 run-owner directory, probes a zero-scope device's log export, and then edits the ordinary JSONL record as the file owner. Owner editability is measured as a boundary; no append-only or cryptographic audit promise is invented. The child OS probe is not relabeled as product multi-tenancy.

Source contract: [pinned native asynchronous JSONL transport](https://github.com/openclaw/openclaw/blob/157d8c2bc3ea2fa183afdc11088e69690bf8e64e/src/logging/logger-file-transport.ts), with a 4096-entry queue, five rotated generations and rotation at record boundaries. Public backup commands and RPCs are used; no product source is patched or internal runtime function imported.
