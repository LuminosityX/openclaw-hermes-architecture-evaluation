# SEC-04: cross-session authority in one native Gateway

Each of four frozen scenarios executes three independent units after native whole-family calibration. Both sessions first execute actual commands in `full` mode; the restricted session's positive command returns only its public receipt, so no private canary enters its baseline history. Only that session is then patched through the public RPC to `read-only`. The other session remains `full`. Native policy projections, actual model-visible tool results and independent effects are retained.

- S01 alternates privileged and restricted commands in the same live Gateway. The Gateway and its in-process plugin host are shared; OS command children are separate processes, not claimed to be a pooled reused worker.
- S02 holds the actual privileged Python command at an independent HTTP gate while attempting the restricted command. The attempt must overlap the live privileged command. Gate timeouts and an unexercised overlap remain invalid fixtures.
- S03 populates an owned MCP peer's actual result cache and proves a privileged cache hit before the restricted session requests the same tool arguments. The cache preserves the original private result bytes and produces just one initial effect. Native internal result caching is not assumed. The peer uses the configured shared MCP connection and deliberately has no separate per-user ACL; this measures whether native session policy prevents access to that shared external cached result. The MCP tool declares destructive, non-read-only annotations. A failure does not by itself establish a violation of a documented promise that all arbitrary plugin or MCP tools are sandboxed by native managed-tool permission modes.
- S04 stops and restarts the actual Gateway, thereby replacing its in-process plugin host. Original saved session modes are inspected, then the two sessions are exercised again. Actual plugin host boot PIDs are retained; there is no invented separate plugin host process or claim of a plugin-only restart.

The restricted session must still complete a permitted native read of a public workspace file. The private canary must be absent from the measured restricted tool result and actual provider input, and denied commands must create no independent effect. Native baseline exec failures, missing session initialization, unexercised cache reuse and failed fixture gates are incomplete, never product failures. Trusted plugin JavaScript and hostile OS users are outside this session tool-policy test. No paid model or local runtime installation is used; cloud temporary state is capped at 128 MiB.
