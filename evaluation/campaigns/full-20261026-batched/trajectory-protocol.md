# OBS-06: open trajectories and causal linkage

Six frozen scenarios, three fresh independent units each, run against the pinned unmodified core after whole-family calibration. Public `api.on` reference observer hooks write only fields supplied by the native hook events to the native JSONL logger, with independent receipt/timestamp observations at an owned loopback server. Native `chat.history` and `logs.tail` provide the public exports. These reference observer records are distinguished from default core-only history; completeness is not attributed to instrumentation that was absent. No internal model reasoning is expected or inferred.

- S01 joins native model-call start/end IDs and native input/output run, session, provider and model fields. Available upstream request ID hashes are recorded without inventing an absent provider ID.
- S02 compares actual public tool arguments and receipts with native tool-call IDs, supplied durations and independent effect times.
- S03 compares before/after hooks and native run linkage against the independently observed commit order. Hook registration and ordinary task completion have separate positive controls.
- S04 invokes actual native `sessions_spawn`, retrieves the returned child session, waits for the child's independently observed tool receipt and exports parent/child history. Native parent-child hook linkage is scored separately from the child's task outcome. A synthetically manufactured child transcript is never used.
- S05 injects one actual HTTP 503 into the owned provider endpoint, then cancels another actual live tool at its independent gate through `sessions.abort`. Native explicit retry/error evidence, native IDs and cancellation acknowledgement are inspected. A task/session label containing “RETRY” is never evidence of an observable retry. SDK retries with no exported attempt diagnostic remain a possible failed visibility criterion. Server-side effects after cancellation are retained without inferring reversal.
- S06 uses an actual private prompt/file result with a configured synthetic secret pattern. It requires the live model to see the synthetic secret while full-pattern matching native public history and observer/file exports are redacted. Other formats and masked fragments are outside that exact-pattern assertion.

The provider is deterministic and incurs zero paid-model calls. These are trajectory-access measurements, not model-quality or token-cost estimates. All fixtures, native state and outputs are bounded on disposable GitHub workers. The observer hooks and supplied fields follow the [pinned public hook contracts](https://github.com/openclaw/openclaw/blob/157d8c2bc3ea2fa183afdc11088e69690bf8e64e/src/plugins/hook-types.ts).
