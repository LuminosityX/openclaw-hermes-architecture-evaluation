# EXT-03: actual old/new host comparison and extension contracts

Four frozen scenarios each run three independent units after whole-family calibration. The campaign target remains OpenClaw `2026.10.7`. Only the version-comparison experiment additionally installs the explicitly pinned previous same-series release `2026.10.6`, source `fe06181dc5ecc01cf8904abbfc26925925efefbc`, as a historical control. Its npm integrity, installed build commit, package lock and CLI SHA-256 are independently verified. Both runtime installations and their shared npm cache are capped at 4 GiB on the disposable host; the previous core is mounted read-only and never installed locally.

- S01 first installs and actually executes the reference extension on the real previous core. It then installs the byte-identical extension archive on the current pinned core and requires its real native tool to execute the same receipt contract. A `builtWith` label or syntax check is not a historical compatibility control.
- S02 verifies a caller omitting an additive optional extension-tool argument still works, then supplies the field and checks its real Unicode value reaches the native result. This exercises extension-tool schema evolution and caller compatibility; it does not claim every upstream Plugin SDK change has been tested.
- S03 registers a real optional native plugin tool, observes its absence without explicit opt-in and verifies attempts do not dispatch. The same immutable artifact must provide the actual capability after tool-policy opt-in and native restart. This is genuine optional plugin-tool capability absence, not a fabricated missing core SDK function.
- S04 first proves healthy reference registration, then enables the artifact's declared startup-failure condition. Native diagnostics must show its actual registration exception; unrelated native provider/tool controls must still work and the failed extension must not dispatch. Correcting only the owned plugin configuration and restarting must restore the original artifact.

No native core or canonical state is patched. Actual previous/current invocations, identical archive hash, native advertised tool catalogs, native registration errors, opt-in configuration and independent effects remain in bounded cloud evidence. Each scenario uses fresh state; the old host comparison is not promoted into current-target observations. At most 128 MiB experiment state is retained temporarily on GitHub workers and no paid model is used.
