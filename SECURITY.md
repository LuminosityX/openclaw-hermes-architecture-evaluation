# Security

This repository contains a historical evaluation harness and intentionally exercises process termination, filesystem faults, policy enforcement, and installation changes. Offline repository checks do not execute those scenarios.

Do not commit real model credentials, authentication state, user conversations, raw execution logs, or databases. The published fixtures use synthetic data; evaluator-only fixtures are not a place to store secrets.

Report exposed credentials or security issues privately to the repository owner through an established private channel. Include the affected commit and path with sensitive values removed. Do not post credentials or private logs in an issue or pull request.

For vulnerabilities in the evaluated products, use the relevant upstream project's reporting process. This archive does not provide security updates for those products or their historical dependencies.
